# Known issues & fixed-bug log

> Purpose (owner request 2026-07-16, item 11): every bug found in HikRAD — fixed or still open — gets a row here with its root cause, so future work (human or AI) never has to guess at symptoms that were already diagnosed. **Append-only discipline: add rows, update Status, never delete.** All phases are required to maintain this file.
>
> **Status convention (added v4-0, FR-114):** every row lives under exactly one of the three headings below — **Open**, **Wontfix**, or **Closed** — which *is* its Status. Every row under Open additionally carries a bolded `**[OPEN — owning phase: vN-M]**` marker at the start of its last cell, naming the v4 phase that will fix it (an open row with no owning phase is a planning bug). Every row under Wontfix carries `**[WONTFIX]**` plus its reason. This is deliberately section-based rather than two extra literal table columns: several of these rows are dense multi-paragraph cells, and splitting every one into more `|`-delimited columns mechanically risked corrupting content for no reliability gain over an unambiguous heading. Rows already resolved (their own text says FIXED/ADDRESSED/REDESIGNED) live under Closed regardless of which historical section they were first filed under — several were filed under a stale "Open" heading before this triage.

Format: newest first inside each section. Cite the fixing commit once pushed; deeper war stories live in the phase gate results linked below.
